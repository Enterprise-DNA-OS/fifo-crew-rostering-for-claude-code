---
description: Draft the cover email to a client's site contact with the crew list and every credential they require, before mobilisation.
---

1. Run `npm run docs -- crew-pack <job>` and `npm run roster -- job <job> --json`.
2. If anyone booked is not cleared, stop and tell the operator first. Never send a client a pack with a lapsed credential in it.
3. Write the email to `drafts/crew-pack-<job>-<date>.md`: who it is to (the client contact), the job and dates, the crew by trade, and that the pack is attached. Plain and short.
4. Never send it. Say where the draft and the pack are.

---
description: Draft a request to a labour hire firm for people to fill a gap: trade, dates, site, and what each person must hold.
---

1. Run `npm run roster -- fill <job> --trade=<trade> --json` and `npm run roster -- job <job> --json`.
2. If the site is in Queensland, check the firm's licence first (`/providers`). Never draft a request to a firm with no Queensland licence for Queensland work; say why.
3. Write it to `drafts/labour-<job>-<trade>.md`: how many, the trade, the dates, the swing, the site and travel, and every credential the site requires.
4. Never send it.

---
description: Add or renew a credential: an induction, medical, VOC, ticket or high risk work licence.
---

1. Run `npm run roster -- credential <worker> <type> --expires=<date or never> [--ref=<number>] [--issued=<date>]`. `npm run roster -- credential-types` lists the types.
2. If they read it off a photo of the card, never guess a digit or a date: ask.
3. Say which gates it clears (`/compliance`).
